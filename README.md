# HAK AI Skills

Kho hướng dẫn kỹ năng AI dùng chung để phát triển và kiểm thử phần mềm HAK.

## Danh mục dự kiến
- `hak-code-auditor`
- `hak-smart-filter`
- `hak-ui-designer`
- `hak-payroll-validator`
- `hak-data-integrity`
- `hak-electron-security`
- `hak-release-builder`
- `hak-migration-manager`

Mỗi skill cần `SKILL.md` nêu phạm vi, đầu vào, đầu ra, điều kiện an toàn và kiểm thử.

## Trạng thái
Repository khởi tạo. Danh mục trên là đề xuất, chưa phải các skill đã được xây dựng hoặc cài đặt.
